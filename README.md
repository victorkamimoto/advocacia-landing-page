# Modelo de Landing Page — Advocacia Estratégica

Landing page responsiva e otimizada para conversão, desenvolvida como modelo comercial para escritórios de advocacia e advogados autônomos.

🔗 **[Visualizar Projeto Online](https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/)**

## 🎯 Objetivo do Projeto
Criar uma interface moderna, limpa e focada em credibilidade e geração de leads via WhatsApp, fugindo do visual tradicional pesado do setor jurídico.

## 🛠️ Tecnologias Utilizadas
* **HTML5 Semântico**
* **Tailwind CSS** (estilização responsiva *mobile-first*)
* **JavaScript Vanilla** (interatividade de FAQ e carrossel de depoimentos)
* **GitHub Pages** (hospedagem e deploy)

## ✨ Destaques de UI/UX
* Hierarquia visual clara com foco na chamada principal (*Hero Section*).
* Seções estruturadas para autoridade (áreas de atuação, processo de atendimento e prova social).
* Carregamento rápido e compatibilidade total com dispositivos móveis.
